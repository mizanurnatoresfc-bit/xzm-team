# ৩. Menu Mapping — System Control Center (২২টি মেনু)

রুট: `/app/control/<section>`। প্রতিটির "বিদ্যমান" কলামে যা আগে থেকে আছে (পুনঃব্যবহার/লিঙ্ক হবে, নকল নয়) ও "নতুন" কলামে যা সত্যিই নেই। **Phase** = কখন কার্যকর হবে। কার্যকর না হওয়া পর্যন্ত মেনুতে "অসম্পূর্ণ" ব্যাজ।

Phase সংক্ষেপ: **P0** প্রস্তুতি (ড্রিফট মেটানো, Staging সিদ্ধান্ত) · **P1** ভিত্তি · **P2** পর্যবেক্ষণ · **P3** নিয়ন্ত্রণ · **P4** বাকি মডিউল (বিস্তারিত `05`)।

## সারাংশ

- **P1 (ভিত্তি, আপনার নির্ধারিত অগ্রাধিকার):** Master Function Registry (#5), Dependency Mapping (#6), System Settings (#22), Audit Log (#3 + কভারেজ), System Health (#2), Error Logging (#4), Permission Audit (#7), DEMO Test Foundation (#15) + Command Dashboard কাঠামো (#1)।
- **বিদ্যমান থেকে সরাসরি পুনঃব্যবহার:** `audit_logs`, `system_settings`, `login_events`, `notifications`, `permissions/roles/user_roles`, Access Center, Branding/Menu Editor/Role Dashboards, `cron`, Edge Functions, GitHub Actions, `supabase/tests`, `scripts/role-demo`।
- **সত্যিই নতুন:** Registry+Edges, Error events, Health snapshots, Feature flags, Releases, Backups রেকর্ড, Test runs, Integrations রেজিস্ট্রি, Dev tasks, Alert rules (সব `sc_` উপসর্গে)।
- **বিদ্যমান মেনুর সাথে সংঘাত:** আজকের সিস্টেম-গ্রুপে (`ইউজার ও রোল`, `অ্যাডভান্সড রোল ও পারমিশন`, `রোলভিত্তিক ড্যাশবোর্ড বিল্ডার`, `নাম, লোগো ও রঙ`, `মেনু এডিটর`) — এগুলো **সরানো হবে না**; নতুন গ্রুপে লিঙ্ক থাকবে (মালিকের "মেনু থেকে সরানো"-ধরনের সিদ্ধান্ত বিদ্যমান ইতিহাসে আছে, তাই কোনো পুরনো মেনু নিজে থেকে সরাব না)।
